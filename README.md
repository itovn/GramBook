# Trang GramBook (nhánh gh-pages của itovn/GramBook)

Trang giới thiệu và nguồn Cydia của [GramBook](https://github.com/itovn/GramBook) — đọc sách / ebook lưu trên Telegram cho iPhone /
iPad iOS 5 / iOS 6 đã jailbreak.

- Trang: https://itovn.github.io/GramBook/
- Nguồn Cydia: `https://itovn.github.io/GramBook/cydia/` — tạo bằng `tools/update-cydia-repo.sh` của repo GramBook.

Trang viết cho Safari iOS 5 / 6 (không biến CSS, flex, grid; dải màu có tiền tố `-webkit-`).
